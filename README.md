# clock_widget

A new Flutter project.

Flutter hanya dipakai sebagai **theme picker**. Widget-nya murni Android
(`ClockWidgetProvider` + `res/layout/widget_theme_*.xml`), punya 4 theme:
Pastel Bubbles, Green LED, Flip Clock, dan Minimal.

> 📄 Proses reverse engineering aplikasi "StandBy Mode" yang jadi acuan desain,
> termasuk identifikasi font, palet warna, dan pengukuran geometri —
> lihat [`REVERSE_ENGINEERING.md`](./REVERSE_ENGINEERING.md).
